# Звукоряд

Сайт, где можно играть на любом музыкальном инструменте прямо в браузере: пианино, гитары, скрипка, барабаны, флейты, калимба, хэндпан, терменвокс и ещё 128 инструментов оркестра General MIDI.

**Сайт в интернете:**

- https://play-any-instrument.onrender.com — на Render
- https://bcvfn7007.github.io/play-any-instrument/ — на GitHub Pages

Обе копии собираются из ветки `main`: после каждого `git push` они обновляются сами примерно за минуту.

## Как запустить

**Проще всего:** дважды щёлкните `Запустить.bat`. Откроется браузер с сайтом.

Или в терминале:

```bash
npm start
```

и откройте http://localhost:5173. Нужен только Node.js — никаких пакетов устанавливать не надо.

Без Node.js можно просто открыть `index.html` в браузере.

## Как выложить в интернет (Render)

Render бесплатно выкладывает сайт как «статический»: ничего собирать не нужно, публикуется сама папка. Настройки уже лежат в `render.yaml`.

1. Положите проект в репозиторий на GitHub.
2. Зайдите на [render.com](https://render.com) и войдите через GitHub.
3. Нажмите **New → Blueprint**, выберите репозиторий и нажмите **Deploy Blueprint**. Render сам прочитает `render.yaml`.
   Можно и вручную: **New → Static Site**, выбрать репозиторий, поле Build Command оставить пустым (если Render не пускает дальше — написать `echo ok`), в Publish Directory написать `.`.
4. Через минуту сайт откроется по адресу вида `https://play-any-instrument.onrender.com`.

После каждого `git push` Render обновляет сайт сам.

### Свой сервер для «Играть вместе»

Друзья находят друг друга по нику через серверы знакомств PeerJS. Общий бесплатный `0.peerjs.com` доступен не всем: Chrome с «защищённым DNS» шифрует имя сайта (ECH), а в России такие соединения с Cloudflare обрывают. Поэтому есть и свой сервер — папка `server/`, бесплатный веб-сервис на Render. Сайт выходит в сеть сразу через оба.

1. На Render: **New → Blueprint**, тот же репозиторий, в поле **Blueprint Path** написать `server/render.yaml`, нажать **Deploy Blueprint**.
2. Сервер появится по адресу `https://zvukoryad-peer.onrender.com` (его ждёт `js/online.js`). Проверка: по адресу `/health` пишет `ok`.
3. Необязательно — ретранслятор TURN для сетей, где браузеры не соединяются напрямую: в Cloudflare раздел **Realtime** (раньше **Calls**) → **TURN** → создать ключ, а его ID и API-токен вписать на Render в **Environment** сервиса как `TURN_KEY_ID` и `TURN_KEY_API_TOKEN`.

Бесплатный сервер засыпает, если 15 минут в сети никого нет, и просыпается около минуты — сайт будит его, когда открывают «Играть вместе».

## Как играть

- **Мышкой или пальцем** — нажимайте клавиши, лады, пэды, струны. Можно вести не отрывая — получится глиссандо, на гитаре и арфе — перебор.
- **Клавиатурой компьютера** — нижний ряд `Z…M` и верхний `Q…P` играют ноты, `←` `→` меняют октаву, `Пробел` — педаль (на гитаре — бой, в драм-машине — старт). Работает и в русской раскладке.
- **Аккорды одной клавишей** — кнопка «Аккорды» на пианино и других клавишных: цифры `1…=` (или кнопки под клавиатурой) играют целый аккорд — C, Dm, Em, F, G, Am, G7, E, E7, D, A, Hm, — а буквами можно вести мелодию. Обычная клавиатура компьютера часто не берёт больше 2–4 клавиш сразу, а так хватает двух.
- **Настоящим инструментом** — кнопка с вилкой на панели (или «Настройки → Настоящие инструменты»):
  - MIDI-клавиатура, электронные барабаны, MIDI-гитара (Chrome, Edge, Opera). Удары на 10-м MIDI-канале звучат барабанами на любом инструменте.
  - Микрофон или звуковая карта: гитара, скрипка, флейта, голос. Есть тюнер, режим «Играть звуком сайта» (поёшь — звучит труба) и «Без звука» — сайт только слушает ноты и засчитывает их в «Разучить мелодию». Можно слышать и записывать живой звук вместе с сайтом.
- **Свои клавиши** — кнопка «Свои клавиши» под инструментом: любую ноту, аккорд или удар можно перенести на другую клавишу компьютера или на пэд MIDI-барабанов. Настройка своя для каждого вида раскладки.
- **Играть вместе** — кнопка с человечками: придумайте ник, и друг подключится к вам по нему (или по ссылке-приглашению). Регистрация не нужна. Каждый играет на своём инструменте и слышит остальных; в комнате до 8 человек, есть чат и передача живого звука микрофона. Браузеры соединяются напрямую (WebRTC), а найти друг друга по нику помогают серверы PeerJS: общий бесплатный и свой (папка `server/`).
- **Барабаны** — нарисованная установка: бейте по барабанам и тарелкам, по краю малого — удар по ободу, в центр райда — колокол. Есть вид «пэды», драм-машины TR-808 и LinnDrum, табла, дарбука, тайко, джембе с кахоном, ложки с трещоткой.
- **Разучить мелодию** — кнопка на панели инструмента: выберите песню («Ёлочка», «Кузнечик», «Ода к радости» и другие), и нужная нота будет мигать. Мелодия идёт дальше, только когда нажата верная нота. Кнопка «Послушать, как звучит» сыграет песню сама. Есть на всех инструментах, кроме барабанов, драм-машины и терменвокса.
- **Свои мелодии** — «Разучить мелодию → Добавить свою мелодию»: MIDI-файл из интернета, ноты MusicXML из MuseScore (.musicxml, .mxl), запись песни или голоса (mp3, wav, ogg, m4a) или ноты текстом («до ре ми», «C4 D4 E4»). Из песни с музыкой сайт вытаскивает мелодию голоса (это получается примерно, поэтому есть кнопка «Оригинал» для сравнения и выбор куска — например, только припев); запись одного голоса разбирается точно. У мелодий из записи «Послушать» играет саму песню, а ноты мигают в такт. Можно выбрать, какую партию играть самому, — остальные звучат аккомпанементом. Аккорды нажимаются вместе, есть темп от 25 до 150 % и «Повтор куска» для трудного места. Большие пьесы клавиатура проходит сама, переезжая за мелодией. Мелодии хранятся в этом браузере.
- **Запись** — кнопка «Запись» на панели, готовые записи можно послушать и скачать.
- **Языки** — русский, English, Español, Português, Deutsch. Язык выбирается сам по браузеру, а поменять его можно на главной или в настройках. Вместе с языком меняются подписи нот: «До Ре Ми», «Do Re Mi» или «C D E» (по-немецки — с нотой H).
- **Метроном**, подписи нот (До Ре Ми / Do Re Mi / C D E), светлая и тёмная тема, избранное и недавние инструменты.

## Откуда звук

- У инструментов с пометкой «Живой звук» играют записи настоящих инструментов (библиотека FluidR3 GM, подгружается из интернета по нотам).
- Барабаны: у установки, латинской перкуссии и драм-машины — записи General MIDI (MusyngKite), у TR-808 и LinnDrum — записи этих драм-машин (коллекция smpldsnds). В установке и драм-машине набор можно переключать.
- Если интернета нет — тот же инструмент звучит через встроенный синтезатор. Табла, дарбука, тайко, джембе с кахоном, ложки с трещоткой, хэндпан, балалайка, гусли, терменвокс и синтезаторы всегда синтезируются прямо в браузере.

## Устройство

```
index.html            страница
css/style.css         оформление (тёмная и светлая темы, телефоны)
js/i18n.js            выбор языка и перевод: App.t('Русский текст')
js/i18n/*.js          словари: en, es, pt, de (ключ — русский текст)
js/notes.js           ноты, частоты, цвета нот, раскладка клавиатуры
js/audio.js           аудиодвижок: громкость, эхо зала, метроном, запись
js/synth.js           синтез ~60 тембров и ударных
js/sampler.js         загрузка записей живых инструментов
js/drums.js           ударные: звуки и наборы записей (акустика, TR-808, LinnDrum)
js/instruments.js     каталог инструментов
js/songs.js           мелодии для режима «Разучить мелодию»
js/surface.js         касания, мышь, общие элементы интерфейса
js/pitch.js           высота звука с микрофона и из записи (алгоритм YIN)
js/melody.js          мелодия голоса из песни с музыкой (по методу Melodia, в фоновом потоке)
js/midifile.js        чтение MIDI-файлов
js/musicxml.js        чтение нот MusicXML и .mxl (с повторами и лигами)
js/library.js         «Мои мелодии» в хранилище браузера (IndexedDB)
js/learn.js           «Разучить мелодию»: шаги, аккорды, аккомпанемент, темп, повтор
js/mysongs.js         добавление своих мелодий и выбор партии
js/keybind.js         «Свои клавиши»
js/live.js            настоящие инструменты: MIDI и микрофон, тюнер
js/online.js          «Играть вместе» по нику (PeerJS)
js/layouts/*.js       способы игры: клавиши, гриф, пэды, пластины, калимба,
                      струны арфы, хэндпан, терменвокс, драм-машина,
                      нарисованная барабанная установка
js/app.js             главная, экран игры, настройки
server/               свой сервер знакомств PeerJS для «Играть вместе» (веб-сервис на Render)
```

Чтобы добавить инструмент, допишите строку в `js/instruments.js`: название, значок, способ игры (`layout`), синтез (`voice`) и, если есть, запись General MIDI (`gm`).

Чтобы добавить песню, допишите её в `js/songs.js`: ноты пишутся как `E4 E4 F4 G4:2` (после двоеточия — длительность в долях, по умолчанию 1). Лучше в до мажоре — под инструмент мелодия сдвинется сама.

Чтобы перевести новую надпись, оберните её в `App.t('Текст')` (подстановки — `App.t('Привет, {name}', { name })`) и добавьте строку в каждый словарь в `js/i18n/`. Чего нет в словаре, показывается по-английски, а если нет и там — по-русски.
